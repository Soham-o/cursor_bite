# Security Policy

## Supported versions

Security fixes are targeted at the latest version on the `main` branch.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Instead, use GitHub's private vulnerability reporting feature for this repository when available. Include enough information to reproduce the issue without exposing real credentials, personal data, API keys, or other sensitive information.

Cursor Bite is designed to avoid telemetry and unnecessary external transmission. Reports involving privacy boundaries, clipboard handling, sensitive-data detection, provider isolation, or unintended network access are especially important.
